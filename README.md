## 1. 制作アプリのタイトル

美文字ログ

## 2. 制作アプリの説明（40文字程度）

スマホで文字を練習し、改善点と記録を振り返りながら、自分の字の成長を感じるアプリ。

## 3. 工夫した点・こだわった点

- スキマ時間にスマホで1文字ずつ練習できるように、CanvasとPointer Eventsで指・ペン・マウスの入力に対応しました。
- 点数だけでなく、位置・大きさ・縦横比をお手本と比べた改善コメントを1つ表示し、次の練習で意識する点を分かりやすくしました。お手本との重ね合わせやスタンプも表示します。
- 線の太さの影響を抑える形状採点を追加しました。お手本の中心線と自分の筆跡を比べ、従来の総合点とは別に形状点を表示・保存します。
- 保存した記録の改善コメントを振り返れ、最初と最高点の筆跡を並べて比較する「成長の証」を作りました。
- 手書きの線を座標データとして保存し、お手本は採点時の画像を残すことで、後からお手本を変更しても当時の練習結果を見返せるようにしました。
- 自分でお手本画像を登録でき、練習記録と登録お手本をJSONでまとめて書き出し・読み込みできるようにしました。重複や容量不足で既存データを失わない処理も工夫しました。
- 描画開始・一時停止を切り替えて誤描画を防ぎ、保存後の記録確認から戻ると次の練習を始められるようにしました。スクロール時のタブ固定やToast通知も追加しました。
- 全データ削除は記録一覧の最下部にある折りたたみ欄へ置き、確認と事前バックアップの導線を設けました。

## 4. 次回トライしたこと（または機能）

- スマホ実機で指・ペン入力や画面回転時の操作を確認し、使いやすさと採点基準を調整すること。
- 比較する過去の記録を自由に選び、成長を振り返れる機能。
- 文字全体の配置だけでなく、個々の線や字形の特徴に基づいた改善コメント。

## 5. 備考（感想、シェアしたいこと等なんでも）

自分がスキマ時間に使い、改善点を意識して別の日にも書き、過去の記録から成長を感じられるアプリを目指しました。

採点はお手本との位置・大きさ・縦横比の近さを示す目安です。文字の正誤や、とめ・はね・はらいは評価していません。点数に加えて、筆跡の比較や改善コメントを振り返る体験を大切にしています。

使用技術はHTML・CSS・JavaScript・Canvas・localStorageです。記録は端末のブラウザに保存され、JSONファイルで移せます。

標準のお手本にはKlee One Regularを同梱しています。[配布元](https://github.com/fontworks-fonts/Klee)／[SIL Open Font License 1.1](fonts/klee-one/OFL.txt)

描画、記録カードの表示、保存・採点の処理を分離し、CSSを読みやすい形式に整理しました。Node.jsの標準テスト機能で73件の回帰テストを実行できます。

詳しい機能・使い方・起動方法・テスト手順は、[使い方・技術仕様（以前のREADME）](README_GUIDE.md)にまとめています。

現在の仕様と残作業は[MVP仕様・開発計画](docs/MVP_PLAN.md)を参照してください。
