# 美文字ログ：MVP仕様・開発計画

最終更新：2026年11月16日／提出日：2026年11月26日／提出方法：GitHub

本書は現在の実装に対応する仕様です。初期計画と変更経緯は[実装履歴](IMPLEMENTATION_HISTORY.md)、操作手順は[利用ガイド](../README_GUIDE.md)に分けて管理します。

## 目的と利用場面

自分がスキマ時間にスマホで一文字ずつ練習する。位置・大きさ・縦横比の改善点を知り、別の日にも練習し、筆跡の比較から成長を感じる。

基本の流れ：文字選択 → 描画開始 → 手書き → 採点・重ね合わせ → 保存 → 記録の確認・成長比較。

## 実装状況と技術

MVPおよびバックアップ・画像お手本登録・並べ替え・全データ削除を実装済み。実機での操作確認と採点基準の調整を継続する。

- HTML・CSS・標準JavaScript。jQuery・ビルドツール・外部パッケージは使用しない。
- CanvasとPointer Eventsで指・ペン・マウス入力に対応。
- 保存先は端末・ブラウザ・オリジンごとのlocalStorage。サーバー・アカウント・自動同期はない。
- 標準文字：ひらがな清音46文字、漢字39文字。初期選択は「原」。一覧は `js/characters.js` で管理。
- お手本は明朝系フォント。`img/` の画像指定、ブラウザからの登録画像にも対応。
- 実行にはCanvas、Pointer Events、dialog、Popover、CSSのsticky・:hasに対応するブラウザを使用する。

## 書く画面

- お手本、文字選択、手書き欄を近くに置く。十字ガイドを表示する。
- 初期状態はスクロール可能。「文字を書く」で描画を有効にし、「一時停止」で筆跡を残してスクロールへ戻す。
- 複数の指の混入を防ぎ、筆跡は0〜1の座標で保持。表示サイズが変わっても比率を保つ。
- 未入力では採点不可。点だけの入力は採点時に案内する。
- 「書き直す」で筆跡・採点結果を消す。文字変更時に筆跡があれば確認する。
- 採点後は筆跡を固定し、自動でスクロール状態へ戻す。
- 保存成功後は「記録を見る」「練習再開」を横並びに表示する。
- 「練習再開」は同じお手本で筆跡・採点を消して描画を有効にする。
- 「記録を見る」は保存した記録の詳細を開き、次に「書く」へ戻ると空欄・描画有効の状態にする。
- 通常のタブ切り替えでは書きかけを保持し、描画モードだけ解除する。
- 前回の改善コメントの常時表示は行わず、記録詳細から確認する。

## 評価・改善コメント

改善コメントと重ね合わせが主役。点数とスタンプは補助とする。

| 項目 | 比較する特徴 |
| --- | --- |
| 位置 | お手本と筆跡の中心位置 |
| 大きさ | お手本に対する幅・高さ |
| 縦横比 | お手本に対する横長・縦長の度合い |

- 評価方式は `layout-v1`。計算式・点数帯・しきい値は `js/evaluation.js` を正とする。
- 項目別の差に基づき改善コメントを1件表示。差が小さければ良い点を伝える。
- スタンプは点数帯に応じて3種類。`img/` の160×160透過PNGを使用。
- お手本を薄いグレーで重ね、筆跡は黒で表示。位置・倍率は自動補正せず差を残す。
- 採点結果の「お手本を重ねる」はお手本のみを切り替える。記録詳細はお手本とスタンプを一緒に切り替える。
- 文字の正誤、書き順、個々の線、とめ・はね・はらいは評価しない。
- 採点結果の注意文「点数はあくまで目安です」は画面に常時表示しない。採点の限界はREADME・ガイドで説明する。

## 記録一覧・詳細

- 採点時に保存用のIDを発行し、同じ採点結果は重複保存しない。
- 一覧は筆跡・文字・総合点・日時を表示。初期表示は日付の新しい順。
- 「表示」行に文字絞り込みと並べ替えを1行で配置。
- 並べ替えは日付・点数それぞれの昇順・降順。点数が同じなら新しい日時を優先し、日時も同じなら元の順序を保つ。
- 詳細は「○の記録」の右に日時、お手本切替と総合点を同じ行に表示する。
- 画像の下に位置・大きさ・縦横比の項目名と点数を1行で並べ、その下に改善コメントを表示する。
- 個別削除は文字幅＋左右20pxの控えめなボタン。確認欄で確定した場合だけ削除する。
- 保存した評価を表示し、過去の記録を再採点しない。

## 成長の証

- 練習数は保存記録の件数、練習日数は保存された練習時のローカル日付の種類数。
- 左は文字ごとの最初の記録、右は総合点の最高記録。最高点が同点なら日時が新しい記録を選ぶ。
- 日時も同じなら保存配列の順序で新しい保存を優先する。最初の記録は同一日時の中で古い保存を選ぶ。
- 1件だけの場合や最初が最高点の場合は、左右に同じ記録を表示する。
- 見出し「最初の自分」「最高点の自分」は一覧上部に1セット。文字ごとの見出し・回数表示はない。
- 点数と右揃えの日時を1行にまとめる。点数は以前の表示から1.5倍に拡大している。
- 比較対象のお手本画像または評価方式が異なる場合は注記する。
- 保存・削除・読込・別タブの保存データ変更に応じて集計を更新する。

## お手本の登録・削除

- 文字選択の「画像のお手本を登録」から1文字の名前と画像を登録する。標準一覧にない文字も登録可能。
- PNG・JPEG・WebP、10MB以下、4000万画素以下。文字名は空白を除きUnicode NFCで正規化した1文字。
- 白背景へ合成し、縦横比と余白を保った600×600 PNGへ縮小。縮小後のデータ長にも上限を設ける。
- 白紙・小さすぎる文字・読めない画像は拒否する。
- 同じ文字の置換や書きかけの破棄は確認チェックを必要とする。
- 登録画像は「登録」カテゴリから選択。削除には確認を設ける。登録お手本を削除しても過去の記録と当時のお手本画像は残る。
- 標準画像の読込失敗時はフォントへ戻す。フォント字形は端末により異なる。

## 保存・バックアップ・全データ削除

- 統合キーは `bimoji.data.v1`。旧 `bimoji.records.v1`・`bimoji.templates.v1` は次の保存成功後に移行する。
- 記録にはID、文字、ISO日時、ローカル日付、正規化座標、総合・項目点、コメント、スタンプ、採点時のお手本PNG・種類・バージョン・フォント等を保存。
- バックアップは `bimoji-log-backup` 形式のJSON、バージョン2。全記録と登録お手本の文字名・画像・更新日時を含む。旧バージョン1の記録も読込可能。
- 文字の絞り込みに関係なく全件を書き出す。JSON読込の上限は10MB。
- 読込は追加・重複・内容違いの件数を確認後に実行。既存を優先し、同じIDや文字名の内容違いを上書きしない。
- 構造検証後、両方を1回の保存で追加。容量不足・不正ファイルでは部分追加しない。
- 読めない既存データは自動で初期化しない。保存・通常の削除は停止するが、明示的な全データ削除で初期化できる。
- 「記録」最下部の折りたたみ「データ管理」→「全データを削除」→確認画面で「削除する」の順に全削除する。
- 確認画面には復元不可・全件対象を明記し、「先にバックアップする」「キャンセル」も設ける。初期フォーカスはキャンセル。
- 全削除はこのアプリの3キーだけが対象。旧キーの削除途中で失敗しても復活しないよう空の統合状態を先に書き込む。失敗時は完了できなかった旨を表示する。
- 成功後は画面上の下書き・保留中の読込も初期化し、一覧と集計を更新する。

## 通知・画面共通

- 保存・個別削除・お手本登録削除・全削除の成功は画面下部へ4秒間のToast。連続操作では最後の通知に更新する。
- 失敗時は操作欄へエラーを表示。バックアップ・読込の通知には「×」を設け、閉じると余白も消す。
- 「書く」「記録」「成長の証」のタブはスクロールで画面上端に達したら固定する。
- アドバイス本文の行間は全画面共通の1.52。スマホ幅に応じて文字サイズ・配置を調整する。

## コード構成・検証

- `app.js`：画面状態、入力イベント、画面遷移、操作と保存の連携。状態は専用スコープに閉じる。
- `canvas-drawing.js`：入力座標、線と保存筆跡の描画、お手本の透過重ね合わせ。
- `record-views.js`：日時表示、記録カードと成長比較カードの要素生成。保存・画面遷移は扱わない。
- `records.js`・`templates.js`：検証とストア、`backup.js`：統合保存と移行・入出力・全削除。
- `evaluation.js`：採点、`characters.js`：標準文字一覧。`css/style.css` は規則順を維持して複数行へ整形。
- 自動テストはNode標準の `node --test tests/*.test.cjs`。描画・表示分離の回帰検証を含め60件。
- スマホ幅で描画→採点→保存→記録確認→再練習、成長比較、画像登録、バックアップ・復元、削除確認をブラウザ検証する。実際の記録を変えず、保存先を分けた確認用画面を使う。
