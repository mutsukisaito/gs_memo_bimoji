# 美文字ログ：MVP仕様・開発計画

決定日：2026年11月15日／提出日：2026年11月26日／提出方法：GitHub

## 目的と利用場面

自分がスキマ時間にスマホで使う。文字を書き、具体的な改善点を知り、別の日に意識して書き、記録を見比べて成長を感じる。

基本の流れ：文字選択 → 手書き → 評価・重ね合わせ → 保存 → 後日比較。過去の改善コメントは記録の詳細から確認する。

## 技術と対象文字

- HTML・CSS・JavaScript。jQueryは利用可。現段階は標準JavaScriptで実装。
- Canvasでお手本・手書きを表示し、Pointer Eventsで指・ペン・マウス入力に対応する。
- 記録はlocalStorageに保存する。サーバー・ユーザー登録は設けない。
- ひらがな清音46文字：あいうえおかきくけこさしすせそたちつてとなにぬねのはひふへほまみむめもやゆよらりるれろわをん
- 漢字39文字：原、夢、福、岡、庵、無、見、同、紅、花、彩、投、資、目、標、子、川、辺、春、夏、秋、冬、健、康、豊、作、夕、内、暮、口、田、古、由、身、家、屋、金、和、透
- 画面案の「文」は例示。実装初期のお手本は対象文字の「原」にする。

## MVPの画面と機能

| 画面 | 必須機能 |
| --- | --- |
| 書く | 文字選択、お手本表示、手書き、書き直し |
| 評価結果 | 重ね合わせ、改善コメント1件、点数、スタンプ、保存 |
| 記録 | 保存記録の一覧、文字による絞り込み、詳細表示、削除 |
| 記録詳細 | 日時、点数、コメント、筆跡、重ね合わせON/OFF |
| 成長の証 | 保存件数、練習日数、同じ文字の最初と最新の記録の比較 |

文字を変更すると書きかけの内容は消えるため、入力済みなら変更前に確認する。書き直しはワンタップで全消去する。

## 評価仕様

改善コメントとお手本の重ね合わせを主役にする。点数とスタンプは補助。

| 項目 | お手本と比べる特徴 | コメント例 |
| --- | --- | --- |
| 位置 | 文字全体の中心 | 少し右に寄っています。中央を意識してみましょう |
| 大きさ | 文字全体の幅・高さ | もう少し大きく書いてみましょう |
| バランス | 文字全体の縦横比 | お手本より横長です。横幅を少し抑えてみましょう |

- 文字ごとのお手本を基準にする。正方形に近づける評価にはしない。
- 点数は3項目から算出する「配置の目安」。配分・しきい値は試し書きで調整する。
- 差の大きい項目について改善コメントを1件表示する。差が小さければ良い点を伝える。
- スタンプは点数帯に対応させ、既存素材を確認して使用する。
- 未入力は採点しない。
- 文字の正誤、書き順、個々の線、とめ・はね・はらいは対象外。異なる文字でも外形が似ると高得点になり得る。
- 重ね合わせはお手本を薄いグレー、筆跡を黒にする。筆跡は自動で移動・拡大せず、位置や大きさの差を残す。

## お手本の管理

最初は明朝系フォントを使用する。同じCanvas描画を表示と評価の基準にする。フォントは端末により異なる場合があるため、お手本の識別・バージョンには使用フォントの情報も考慮する。

`js/characters.js`で文字名・分類・画像パスを管理し、後から`img`フォルダに画像を置いて切り替えられるようにする。画像は白背景または透過背景で、文字の周囲に適度な余白があるものを用意する。ブラウザからの画像登録はMVP後に追加する。

## 記録の設計方針（保存機能の実装時に確定）

保存対象：記録ID、文字、日時、正規化した筆跡の線データ、点数、項目別評価、コメント、お手本の識別情報・バージョン。

- 練習数＝保存した記録の件数。
- 練習日数＝保存時点のローカル日付の重複を除いた件数。
- 成長比較＝同じ文字の最初と最新。1件のみなら比較にもう1件必要と案内する。
- お手本を変更した場合も過去の評価と混同しない。過去のお手本表示を再現できる保存方法を評価機能の実装時に決める。
- 保存先はその端末・ブラウザのlocalStorage。別端末とは同期しない。
- 容量不足・保存データ破損は画面で通知し、既存の記録を無断で消さない。
- 記録削除には確認を設ける。
