# 美文字ログ

スキマ時間にスマホで一文字ずつ練習するアプリです。HTML・CSS・JavaScriptで実装しています。

## 現在使える機能

- ひらがな46文字・漢字39文字の選択
- Klee One Regularのお手本と十字ガイド
- 指・ペン・マウスによる手書き、書き直し
- 「文字を書く」と「一時停止」の切り替えによる誤描画防止
- 設定ファイルによる画像お手本への切り替え
- 位置・大きさ・縦横比を比較した採点、改善コメント1件、評価スタンプ
- 線の中心を比較する形状点（従来の総合点とは独立して表示・保存）
- お手本との重ね合わせと表示のON/OFF
- 採点結果のlocalStorage保存、記録一覧、文字での絞り込み
- 記録の詳細表示、採点時のお手本・スタンプの表示切り替え、確認付き削除
- 記録一覧の日付順・点数順の並べ替え（昇順・降順）
- 成長の証：保存した練習数・練習日数、文字ごとの最初と最高点の筆跡の比較
- 全記録と登録お手本の文字名・画像をJSONで書き出し、確認後に既存データを残して読み込む
- ブラウザから文字名とお手本画像を登録し、登録画像で練習・採点
- 記録一覧の最下部から、事前バックアップ・確認を経て全データを削除
- スクロール時のタブ固定、保存・削除時のToast、閉じられるバックアップ通知

保存した記録は再読み込み後も残ります。未保存の筆跡と採点結果は再読み込みで消えます。スマホ実機での通し確認・評価の調整は引き続き行います。

## 記録の書き出し・読み込み

「記録」タブの見出し右側にある「バックアップ」「読込」から操作します。結果の通知は右側の「×」で閉じられます。閉じても書き出したファイルや保存データは変わりません。

1. **バックアップ**：文字の絞り込みに関係なく、保存済みの全記録と登録お手本の文字名・画像を `bimoji-backup-日付-時刻.json` としてダウンロードします。記録0件でも、お手本だけを書き出せます。
2. ファイルをスマホ・別のブラウザへ移す場合は、保存したJSONファイルを移してください。
3. **読込**：美文字ログから書き出したJSONを選びます。上限は10MBです。ファイル名ではなく内容を検証します。
4. 確認画面で記録と登録お手本それぞれの追加・重複・内容違いの件数を確認し、**合計○件を追加する**を押します。キャンセルでは保存データは変わりません。

既存記録・お手本は消しません。同じID・内容の記録、同じ文字名・画像のお手本は重複として読み飛ばします。同じIDや文字名で内容が異なる場合も既存データを優先します。お手本は更新日時だけが異なる場合も同じ画像なら重複です。追加が合計0件の場合は追加ボタンが無効になります。読み込み成功後は一覧・成長の集計も更新し、復元したお手本は文字選択の「登録」から使えます。

バックアップには筆跡、日時、評価、スタンプ情報、採点時のお手本画像に加え、登録お手本の文字名・画像・更新日時が含まれます。別ブラウザで記録を再現し、登録お手本を使って練習を再開できます。未保存の筆跡・未保存の採点結果、標準のお手本一覧の設定ファイルは含みません。

新形式は `{ "format": "bimoji-log-backup", "version": 2, "exportedAt": "ISO日時", "records": [...], "templates": [...] }` です。旧形式のバージョン1も読み込め、その場合は記録だけ追加して既存のお手本は維持します。新形式は以前のアプリでは読み込めません。

形式や記録・お手本が不正なファイル、未知のバージョン、ファイル内でIDやお手本の文字名が重複している場合は全体を拒否します。記録とお手本の両方を検証してから1回の保存で一括追加し、容量不足や保存失敗でも片方だけを追加しません。書き出し元が壊れている場合も自動で初期化しません。

## 成長の振り返り

「成長の証」では、保存した記録の件数を練習数、各記録の練習時のローカル日付の種類数を練習日数として表示します。同じ日に何回保存しても1日です。削除した記録は集計から外れます。

文字ごとに、日時が最も古い記録と総合点が最も高い記録の筆跡・日時・点数を並べます。同点の場合は日時が新しい記録を優先します。最初が最高点の場合や1件だけの文字では、左右に同じ記録を表示します。記録がない場合や保存データを読めない場合も案内します。お手本画像や採点方式が変わった記録の比較には注記を表示します。

「書く」画面はお手本と手書き欄を近づけた配置です。前回コメントの常時表示は行わず、過去の改善コメントは「記録」の詳細から確認します。

## 採点の使い方

1. 文字を選び、手書き欄の上の「文字を書く」を押してから白い枠に一文字書きます。初期状態では枠内からもスクロールでき、触れても線は増えません。
2. 「採点する」を押すと、お手本との重ね合わせ・スタンプ・点数・改善コメントを表示します。
3. 「お手本を重ねる」でグレーのお手本を表示／非表示にできます。
4. 「書き直す」で結果と筆跡を消し、再び「文字を書く」を押すともう一度練習できます。

描画中はボタンが「一時停止」に変わります。途中でスクロール状態にしても筆跡は残り、「文字を書く」で続きを書けます。採点後は自動でスクロール状態になります。採点済みの筆跡は固定されるため、再練習する場合は「書き直す」を使います。文字変更・書き直し・タブ移動時もスクロール状態に戻ります。

## 記録の使い方

1. 採点後、結果の下にある「この練習を保存する」を押します。同じ採点結果は重複保存しません。
2. 「記録」タブで一覧を見られます。初期表示は日付の新しい順です。保存済みの文字で絞り込めます。
3. 記録を押すと日時・筆跡・点数・項目別評価・改善コメントを表示します。
4. 詳細の「お手本・スタンプを重ねる」で、当時のお手本とスタンプを切り替えます。
5. 「この記録を削除する」を押し、確認欄で「削除する」を押すと1件だけ削除します。「キャンセル」で取り消せます。削除後は復元できません。

保存後は保存ボタンの代わりに「記録を見る」と「練習再開」が横に並びます。「記録を見る」は保存した記録の詳細を直接開きます。「練習再開」は同じお手本のまま入力欄と採点結果をリセットし、描画を有効にするので、そのまま次の文字を書けます。保存済みの記録は残ります。

通常のタブ切り替えでは書きかけの筆跡は残ります。保存後の「記録を見る」から移動した場合は、次に「書く」タブへ戻ると筆跡・採点結果を消し、同じお手本ですぐ書ける状態になります。練習欄を消しても、保存済み記録には影響しません。

保存・削除の完了は、画面下部のToastに4秒間表示します。お手本の登録・削除も同様です。操作に失敗した場合は、操作欄にエラーを表示します。上部のタブはスクロールで画面上端に達すると固定されます。成長比較の「最初の自分」「最高点の自分」は一覧の上部にまとめて表示します。

### 全データの削除

「記録」タブ最下部の「データ管理」を開き、「全データを削除」を押すと確認画面が開きます。「先にバックアップする」でJSONを書き出し、保存先を確認できます。「キャンセル」ではデータを変更しません。「削除する」を押すと、このブラウザの練習記録・登録お手本・書きかけの内容をすべて消します。文字で絞り込んでいても全件が対象で、削除は元に戻せません。ほかのアプリの保存データは削除しません。必要なデータは先にバックアップしてください。

### 記録の並べ替え

一覧の「表示」行の右側のセレクトボックスから「日付の新しい順」「日付の古い順」「点数の高い順」「点数の低い順」を選べます。左側の文字の絞り込みと併用できます。点数が同じ場合は新しい日付が先で、日付も同じなら元の並びを保ちます。

選んだ表示順はタブの切り替えや削除後も維持します。ページを再読み込みすると初期表示に戻ります。表示順の変更で保存記録・バックアップ・成長比較の「最初と最高点」の対象は変わりません。

### 保存する内容と注意点

保存キーは `bimoji.data.v1` です。記録と登録お手本を同じキーにまとめ、一括読み込みの保存を原子的に行います。従来の `bimoji.records.v1` と `bimoji.templates.v1` は読み取りに対応し、次の保存が成功してから統合します。移行失敗時は旧キーを削除しません。各記録にはID、練習日時、練習時のローカル日付、文字、正規化した線の座標、評価とスタンプの情報、お手本のPNG画像・種類・バージョンを保存します。

お手本は採点時の画像をそのまま保存するため、後からフォントやお手本ファイルが変わっても当時の重ね合わせを再現できます。筆跡のサムネイルは座標から描画し、画像を重複保存しません。

- 記録はその端末・ブラウザ・URLの保存先に残ります。PCとスマホ、localhostとGitHub Pagesの間で自動同期しません。
- ブラウザのサイトデータ削除で記録も消えます。大切な記録は定期的に書き出してください。
- 継続利用は同じHTTPサーバーまたはGitHub PagesのURLを推奨します。ファイル直接表示ではブラウザによって保存先や利用可否が異なります。
- 容量不足・アクセス禁止・読み込めない保存データは画面で通知します。保存失敗時は筆跡を残し、再試行できます。
- 読めない既存データは自動初期化せず、保存・通常の削除を停止して保護します。明示的に「全データを削除」を確定した場合は初期化できます。

採点後は筆跡を固定します。未入力では採点ボタンが無効になり、点だけの場合は文字を書くよう案内します。

### 点数の意味

赤い総合点は、従来どおり文字の外接範囲の位置・大きさ・縦横比を比較する「配置の目安」です。「形状」は別の点数です。総合点・スタンプ・改善コメント・点数順の並べ替え・成長比較の最高点の選び方には混ぜません。文字の正誤、線の美しさ、書き順は評価しません。

- 位置35%：枠の幅・高さを1としたときの中心の距離。距離0.35以上で項目点0点。
- 大きさ35%：外接範囲の面積の平方根の比。2倍または半分で項目点0点。
- 縦横比30%：お手本に対する縦横比の比。2倍または半分で項目点0点。
- 各項目は0〜100点。差が最も大きい項目から助言を1件表示します。
- 全項目の差が小さい場合（項目点がおおむね88点以上）は良かった点を表示します。
- スタンプ：85点以上「たいへんよくできました」、60〜84点「がんばりました」、59点以下「もうすこしがんばりましょう」。

しきい値は実際の試し書きをもとに今後調整します。評価方式の識別子は `layout-v1` です。画面上の「点数はあくまで目安です」という常時表示は省き、採点の意味と限界は本ガイドで説明しています。

### 形状点の意味

「形状」はお手本の線と筆跡の中心線の近さを0〜100点で表します。線の太さ・筆圧・書く速さは採点せず、位置と全体の大きさをそろえて比較します。縦横比を別々に伸縮したり、傾きを自動補正したりはしません。元の重ね合わせ表示は配置の差を残したままです。

お手本画像を細線化し、自分の字は保存している座標から中心線を描き直します。双方の線までの距離を測り、余分な線と足りない線を両方減点します。小さなずれは許容し、大きな欠けは強めに減点します。評価方式は `shape-v1`、保存先は記録の `evaluation.shape`（方式ID・点数）です。JSONへの書き出し・読み込みでも保持します。

形状点は一致率の百分率や文字認識の正答率ではなく、形の近さの目安です。フォントの交点・線端、画像のぼけや太すぎて接続した線では、細線化後も差が残ることがあります。しきい値は実機での試し書きをもとに調整します。

過去の記録は自動で再採点せず、形状点を持たないものは詳細に「未採点」と表示します。従来のバックアップもそのまま読み込めます。

## 起動方法

ビルドや依存パッケージのインストールは不要です。`index.html`をブラウザで開けます。

ローカルサーバーを使う場合は、プロジェクト直下で以下を実行します。

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

PCでは `http://localhost:8000` を開きます。同じWi-Fiのスマホでは `http://PCのLAN内IPアドレス:8000` を開いてください。ネットワーク設定やファイアウォールによって接続できない場合があります。

GitHub Pagesで公開する場合は、リポジトリのSettings → Pagesで対象ブランチとルートフォルダを指定できます。今回の作業では公開・GitHubへのアップロードは行っていません。

## お手本画像の追加

### ブラウザで登録する

1. 「書く」→「文字を選ぶ」→「画像のお手本を登録」を開きます。
2. 練習したい文字名を1文字で入力し、PNG・JPEG・WebPの画像を選びます。標準一覧にない文字も登録できます。
3. 白背景または透過背景に黒い文字が1文字ある画像を使ってください。余白を含めて600×600の正方形内に縦横比を保って収め、プレビューを表示します。文字位置の自動補正・切り抜きは行いません。
4. プレビューを確認し「登録して練習する」を押します。登録後は「文字を選ぶ」の「登録」から再び選べます。標準のひらがな・漢字のお手本とは別に管理します。
5. 同じ文字を登録し直す場合は「画像を置き換える」にチェックします。書きかけの文字がある場合は「消して登録したお手本で練習する」にチェックします。チェックしないと現在の筆跡を消しません。
6. 削除は、対象の登録お手本を選択してから文字一覧を開き、「選択中の登録お手本を削除」→確認で行います。保存した練習記録と、その採点時のお手本画像は残ります。

入力画像は10MB・4000万画素まで。縮小後のPNGも容量を制限します。白紙・点だけの画像、読み込めない画像、対象外の形式は登録しません。文字の正しさ自体は自動判定しません。余分な線・写真の背景がある画像は採点に影響します。

登録お手本はlocalStorageの `bimoji.data.v1` 内に記録と一緒に保存し、再読み込み後も使えます。容量不足・保存先が壊れている場合は画面で通知し、既存データを上書きしません。登録お手本の文字名と画像もJSONバックアップに含まれます。元画像の保管も推奨します。

### imgフォルダから追加する

1. `img`に画像を配置します。例：`img/hara.png`。
2. `js/characters.js`の漢字一覧生成後に、対応する項目へ画像パスを指定します。

```js
CHARACTERS.find(item => item.character === "原").image = "img/hara.png";
```

白背景または透過背景の画像を使用してください。縦横比を保って枠内へ表示します。画像を読み込めない場合はKlee Oneのお手本を表示します。

標準のお手本は、アプリに同梱したKlee One Regularです。端末へのインストールは不要で、フォントの読込完了後にCanvasへ描画し、同じ画像を採点に使います。読込失敗時は案内を表示し、代替フォントのまま採点しません。登録画像はこれまでどおり使えます。保存済み記録は当時のお手本画像を保持し、再採点しません。

フォント本体は約8.3MiBで、初回アクセス時にアプリから読み込みます。著作権表示とSIL Open Font License 1.1は[同梱ライセンス](fonts/klee-one/OFL.txt)、配布元は[Klee公式リポジトリ](https://github.com/fontworks-fonts/Klee)を参照してください。

## ファイル構成

- `index.html`：画面
- `css/style.css`：スマホ向けの見た目
- `js/characters.js`：文字一覧・お手本設定
- `js/templates.js`：ブラウザ登録お手本の文字名検証・保存・置換・削除
- `js/backup.js`：記録とお手本の統合保存、旧形式移行、両方のバックアップ・読み込み
- `js/evaluation.js`：筆跡の範囲検出・採点・コメント・スタンプ選択
- `js/shape-evaluation.js`：細線化・位置と大きさの正規化・双方向の中心線比較
- `js/records.js`：保存データの検証・localStorage読み書き・削除
- `js/canvas-drawing.js`：入力座標の正規化・線と保存筆跡の描画・お手本の重ね合わせ
- `js/record-views.js`：日時表示・記録一覧と成長比較のカード生成
- `js/app.js`：画面状態・手書きイベント・画面遷移・保存操作の連携（状態は専用スコープ内に保持）
- `tests/canvas-drawing.test.cjs`：座標・描画と再描画の一致・透過重ね合わせのテスト
- `tests/record-views.test.cjs`：記録カードの対象ID・最高点比較・注記のテスト
- `tests/evaluation.test.cjs`：採点計算のテスト
- `tests/shape-evaluation.test.cjs`：太さ・位置・大きさへの不変性、変形・余剰線・欠損の減点、筆記速度・順序への不変性のテスト
- `tests/records.test.cjs`：保存・復元・削除・保存失敗時の保護のテスト
- `tests/templates.test.cjs`：お手本登録・置き換え・削除・保存失敗時の保護のテスト
- `tests/backup.test.cjs`：記録とお手本の一括復元・旧形式互換・統合保存のテスト
- `img/`：アプリで使う画像（160×160に縮小したスタンプ3枚・追加するお手本画像）
- `fonts/klee-one/`：標準お手本のKlee One Regular・ライセンス・配布元情報
- `sozai/`：元画像・提供素材・画面案の手元保管用。Git管理対象外で、アプリからは参照しない
- `docs/MVP_PLAN.md`：現在の仕様・実装状況・提出までの残作業
- `docs/IMPLEMENTATION_HISTORY.md`：初期計画・過去の実装履歴

スタンプ画像は透過PNGのまま200×200から160×160へ縮小しています。以前の記録・バックアップにある `sozai/` のスタンプパスは、読み込み時に対応する `img/` のパスへ変換します。過去の記録も素材フォルダなしで表示できます。

## 手動確認項目

- 文字選択でひらがな46文字・漢字39文字が表示される。
- 選んだ文字がお手本に反映される。
- 初期状態では枠内を触っても線が増えず、スクロールできる。
- 「文字を書く」を押すと指・ペン・マウスで線や点を書ける。描画中は練習枠上でページがスクロールしない。
- 「一時停止」では筆跡を残して描画を停止し、再度「文字を書く」で続きを書ける。
- 枠外ではページをスクロールできる。
- 指が枠を出ても、離した後に線がつながり続けない。
- 2本目の指を触れても筆跡が飛ばない。
- 書き直すと筆跡だけが消え、ガイドは残る。
- 書きかけで別の文字を選ぶと確認が出る。キャンセルすると筆跡が残る。
- 画面の回転・幅の変更後も筆跡が保たれる。
- 文字選択はキーボードでも操作でき、閉じると元のボタンに戻る。
- 未入力では採点できず、点だけの場合は案内が出る。
- 採点後に点数・コメント・スタンプ・薄いお手本が表示される。
- 重ね合わせをOFFにしても筆跡・点数は変わらない。
- 採点後の筆跡は固定され、自動でスクロール状態に戻る。書き直すと結果が消え、「文字を書く」から再入力・再採点できる。
- 保存後に再読み込みしても、一覧と詳細に同じ筆跡・点数・コメント・お手本が残る。
- 同じ採点結果を繰り返し保存しても記録が増えない。
- 一覧を文字で絞り込める。空の一覧でも案内が表示される。
- 詳細でお手本・スタンプをOFFにしても筆跡と点数が変わらない。
- 削除確認でキャンセルすると記録が残り、確定するとその1件だけが消える。
- 書き直し・文字変更をしても保存した記録は残る。
- 同じ日の2件の保存は「2字・1日」となる。
- 同じ文字の最初と最高点の筆跡が並び、1件だけなら左右に同じ記録を表示する。
- 記録を削除すると成長の集計も更新される。
- 書き出したJSONから記録・評価・お手本が復元される。
- 同じバックアップを再選択しても重複追加されず、追加前にキャンセルできる。
- 不正なファイルを選んでも記録は変わらず、再びファイルを選べる。
- 文字名と画像を登録し、その画像で練習・採点・保存できる。
- 再読み込み後も「登録」からお手本を選べる。
- 同じ文字の画像の置き換えは確認チェックがある場合だけ行う。
- お手本を削除しても保存した練習記録と当時のお手本は残る。
- 日付の昇順・降順、点数の昇順・降順で一覧が並ぶ。
- 文字で絞り込んでも並べ替えが適用され、詳細には選んだ記録が表示される。

## 保守時の構成

`index.html` は保存・評価の処理、Canvas描画、記録表示、最後に `app.js` の順で `defer` 読込します。`app.js` は画面間の状態と操作を担当し、保存形式・採点計算・描画・カード生成は専用ファイルに委譲します。動作を変更したファイルを公開する際は、対応する読込URLのバージョンも更新します。

CSSは従来の規則の順番と値を維持して複数行に整形しています。記録・バックアップの形式、保存キー、画像のサイズ、採点方式は今回の整理で変更していません。

現在の仕様は[仕様書](docs/MVP_PLAN.md)、変更当時の経緯は[実装履歴](docs/IMPLEMENTATION_HISTORY.md)を参照してください。
